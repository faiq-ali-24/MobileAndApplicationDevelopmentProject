# SamaanPK - Android App

## Project Overview
This is a clone of the e-commerce app created by Pakistani YouTuber Bilal Munir. Currently, this project is in progress. In Week 2, I implemented the home, category, notification, cart screens, and bottom navigation bar with navigation across pages.

## Setup

### Prerequisites
- **Android Studio**: Latest version
- **Kotlin**: Ensure Kotlin support is enabled in Android Studio
- **Android SDK**: Ensure the SDK is set up in Android Studio

### Steps
1. **Clone the Repository**
2. **Open the Project in Android Studio**
3. **Build the Project**
4. **Run on Emulator Device**

## Screens Designed and Their Purpose

### Home Screen
- Displays featured products and offers.
- Users can scroll through the products and click on them for more details.

### Category Screen
- Shows different product categories like electronics, clothes, etc.
- Users can click on a category to view related products.

### Product Screen
- Displays details of a selected product.
- Users can view images, descriptions, and specifications of the product.

### Category Product Screen
- Shows products under a selected category.
- Users can scroll through products in a specific category and select them for more details.

### Notification Screen
- Displays notifications for user updates like order status, new offers, etc.
- Users can check this screen to stay updated.

### Cart Screen
- Shows products added to the cart.
- Users can adjust quantity, remove items, and proceed to checkout.

### Products List Screen
- Displays a list of all products available in the app.
- Users can browse through the products and click on them for more details.

### Bottom Navigation Bar
- Provides easy navigation between Home, Category, Notification, and Cart screens.
- Users can switch between screens easily with bottom navigation.

### Navigation Drawer
- Offers additional navigation options and settings.
- Users can access various app functionalities from the drawer.
